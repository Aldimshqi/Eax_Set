# Voicemeeter EAX Controler

A utility that synchronizes the EAX Advanced HD control interface with Voicemeeter. Modifying the "Effects Amount" slider in the EAX interface automatically updates the corresponding reverb/echo intensity in Voicemeeter in real time.

## Features

* Real-time synchronization between EAX HD settings and Voicemeeter.
* Automatic adjustment of Voicemeeter effect levels via the EAX slider.
* Lightweight background execution with minimal system overhead.

## Prerequisites

* Windows OS
* Voicemeeter (Potato recommended)

## Installation & Setup

1. Download the latest release from the Releases section.
2. Run Voicemeeter and ensure Remote API integration is permitted.
3. Launch `Eax_Set.exe`.
4. Adjust the "Effects Amount" slider in EAX Settings to control Voicemeeter effects.
